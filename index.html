Spaces

Accounts

Track performance separately across every account you trade — prop firm, personal brokerage, retirement, etc.

Settings

Daily Goal

Set a daily profit target. Your dashboard will assess each day against it and give you feedback aimed at taming overtrading on green days and revenge trading on red days.

Manage Accounts

Accounts used in the "Add Trade" form and the Accounts performance report.

Sync with Google Sheets

Keeps a shared Google Sheet as the common copy of your trades across every device. "Sync Now" pulls in any trades added elsewhere, merges them with what's on this device (newest edit wins), and pushes the combined result back — do this on both your desktop and mobile browser to keep them lined up. Requires a Google OAuth Client ID from your own Google Cloud project (Sheets API enabled, Web application type, this page's origin added to Authorized JavaScript origins). Your credentials stay in this browser only, and each device needs to sign in with Google once — there's no way around that without a backend server, which this app doesn't have.

Note: deletions don't sync across devices yet — delete a trade on each device separately, or it can reappear from the shared sheet on your next sync.

Sync from Interactive Brokers

IBKR doesn't expose a browser-based live sync API, so upload a CSV export of the Trades section from a Flex Query or Activity Statement (Report → Flex Queries, or Reports → Activity). Executions are automatically matched FIFO into round-trip trades.

Reset Data

Permanently clears all trades, accounts, and settings from this browser, leaving a completely blank journal so you can start fresh.
