Google Sheets (Master Record)

Your Google Sheet is the master record of your journal — it's what got loaded when you signed in, and every device/browser you sign into with this same Google account reads and writes the same sheet. "Sync Now" pulls in changes made elsewhere, merges them with this device (editing an existing trade updates that same row; deleting a trade removes it from the sheet too — deletions propagate to every device on their next sync), and pushes the result back. Trades are organized into one tab per year so the sheet stays manageable, but the app always reads every year back in for full historical analysis.

Conflicts: if the same trade or account was edited on two devices since your last sync, the newer edit wins automatically so sync always completes — but it's flagged below so you can review exactly what differed and pick the other version if the auto-pick was wrong.

Import from Interactive Brokers (CSV, historical)

For backfilling history: upload a CSV export of the Trades section from a Flex Query or Activity Statement (Report → Flex Queries, or Reports → Activity). Executions are automatically matched FIFO into round-trip trades. For same-day trades as you make them, see "Live Sync" below instead.

IBKR Live Sync (Beta)

Auto-pulls executed trades from Interactive Brokers while this tab is open. Two data sources — pick whichever you have set up:

Uses IBKR's free Client Portal Gateway — a small program you run on your own computer (there's no way to reach your brokerage account from a purely static, backend-less page otherwise). Setup:

  1. Enable API access for your account in IBKR Account Management (Settings → API → Settings).
  2. Download and run the Client Portal Gateway on this computer.
  3. Open https://localhost:5000 in another browser tab and log in there (accept the self-signed certificate warning — that's expected for a local gateway).
  4. Click "Test Connection" below, then enable Live Sync.

Limitations: only works while this tab is open, the Gateway is running, and you're logged into it. Captures today's fills only. May be blocked by CORS depending on the Gateway's configuration; "Test Connection" will tell you immediately, and there's no code-level fix for that without a backend proxy.

Uses IBKR's Flex Web Service — no local program needed, just your Token and a Query ID. Set up a "Trades" Flex Query (Account Management → Reporting → Flex Queries → create a Trade Confirmation Flex Query, XML format), and enable Flex Web Service under Reporting → Settings to get your Token.

Limitations: this is a server-to-server reporting API, not built for direct browser access — it may not accept requests from this page's origin (CORS), which "Test Connection" will reveal immediately with no code-level fix possible here if so. Report generation isn't instant (a few seconds' delay after each request), and IBKR rate-limits repeated calls, so the check interval has a 5-minute floor here regardless of what you enter.

Market Data (Symbol Lookup)

Powers the "Look Up" button on the Add Trade form: searches a symbol, shows the company/instrument name and exchange, and offers to fill Entry Price with the current live quote. Limitation: none of these expose a historical price for a specific past date/time, only the current quote — genuinely free point-in-time futures/options data isn't available anywhere without a paid provider, since exchanges license that data.

Futures/Future Options note: Twelve Data's free Basic plan does not include Futures/Commodities data — that requires their paid "Grow" plan or higher, so a free key will return "no data" for futures symbols, which is expected. If Twelve Data fails (or no key is set), Look Up automatically falls back to Yahoo Finance's unofficial, no-key endpoint (continuous futures like "ES", "CL", "GC" work best). That fallback is undocumented and best-effort — Yahoo may block direct browser requests entirely (no CORS headers), in which case it will show a clear error rather than silently failing.

Clear Local Cache

Clears this browser's local copy of your data and reloads it fresh from your Google Sheet. Your cloud data is not deleted — use this if something looks out of sync on this device.
